# desBULOtizador

Sistema experimental de verificación de afirmaciones públicas y creación de vídeos explicativos.

## Principios
- Misma metodología para todos los partidos.
- No dar por falso algo antes de comprobarlo.
- Documentar fuentes primarias, fechas y contexto.
- Abstenerse cuando la evidencia sea insuficiente.
- No publicar vídeos automáticamente hasta superar pruebas de calidad y configurar credenciales.
- Presupuesto objetivo: 0 €; sujeto a límites gratuitos de proveedores.

## Estado
Repositorio inicializado. El flujo de prueba manual comprueba el entorno cloud. La investigación, la voz y la publicación real todavía no están desplegadas.
